# Core Rules

- Communicate with the user in Russian. Keep programming terms, code,
  identifiers, and code comments in English.
- Preserve existing behavior unless the requested task explicitly changes it.
- Inspect relevant files before editing them.
- Do not modify unrelated user changes.
- Prefer simple, readable JavaScript suitable for a beginner.
- Use descriptive English names for functions and variables.
- Avoid unnecessary abstractions, dependencies, and duplicated logic.
- Do not mutate input data unless mutation is explicitly required.
- Explain completed changes in simple Russian and include commands needed to
  verify them.
