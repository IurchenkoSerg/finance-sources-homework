# Finance Sources

Vite-приложение получает данные о прибыли из двух API и выводит суммы отдельно
для каждой валюты.

Интерфейс поддерживает русский и английский языки, а также светлую и тёмную
темы. Выбранные настройки сохраняются в `localStorage`.

## Запуск

```bash
npm install
npm run dev
```

После запуска нужно открыть адрес, который Vite покажет в `Terminal`. Обычно:

```text
http://localhost:5173
```

## Проверка

```bash
npm test
npm run build
```

## Структура

- `src/api.js` — запросы к двум API с header `x-api-key`.
- `src/revenue.js` — проверка данных и расчёт прибыли.
- `src/main.js` — загрузка данных и вывод результата на страницу.
- `src/style.css` — внешний вид страницы.
- `src/revenue.test.js` — автоматические тесты расчёта.

## Работа с валютами

`USD` и `EUR` не складываются между собой. Функция возвращает отдельный итог
для каждой валюты в `totalsByCurrency`.

Например:

```js
{
  USD: 3020,
  EUR: 1910
}
```

В реальном production-приложении секретный API key нельзя хранить в client
code. Здесь он находится в `src/api.js`, потому что это прямо требуется в
учебном задании и запрос выполняется из browser.
